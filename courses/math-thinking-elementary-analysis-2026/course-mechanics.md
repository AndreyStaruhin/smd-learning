# Course Mechanics — v0.2

## Назначение

Файл задаёт механику курса. Он не дублирует `core/session-patterns.md`, а конкретизирует его под математику.

## Ритм

- 2–3 стандартные СМД-сессии в неделю по 75–90 минут.
- 1 сессия свободной практики по задачам.
- 1 короткая ревизия артефактов в неделю.
- Мета-сессия раз в 2 недели.
- Сессия схемостроения после каждого крупного понятийного блока.

## Инструменты мыследействия

- Бумага/планшет/доска для ручного решения.
- Markdown-файлы курса.
- `schemes/` для mermaid-схем.
- `evidence-ledger.md` для claims.
- `heat-map.md` для диагностики.
- `onto-map.md` для живой онтологической карты.
- Подгруженные книги как источники задач, понятий и higher viewpoint.

## Режимы

### Ассессмент

Используется в M0. ChatGPT работает как `[Симулянт-эксперт: преподаватель технического вуза]`.

Правила: не гуглить; не просить подсказку; можно говорить «не знаю»; важна не только правильность, но и ход мысли.

### Стандартная СМД-сессия

Фазы: контекст → действие → проблематизация → чистое мышление → возврат → двойная рефлексия.

### Прямой ввод материала

Допустим, если тема `🔴 Cold`. Не больше 20 минут. Структура: Connect → Overview → Pair → Contrast → Anti → Verify → Release.

### Сессия задачной практики

Используется для Сканави и других задачников. Не закрывает T/C автоматически.

Формат:
- выбрать 3–5 задач;
- перед решением указать, какой claim они проверяют;
- после решения зафиксировать тип ошибок;
- если задача решена механически без объяснения — Evidence не закрывается.

### Сессия чтения

Используется для Клейна и Александрова–Колмогорова–Лаврентьева.

Формат:
1. Выделить определения.
2. Выделить утверждения.
3. Выделить примеры.
4. Выделить доказательные ходы.
5. Сформулировать higher-viewpoint сдвиг.
6. Привязать к текущей теме курса.
7. Завести открытый вопрос или claim.

## Evidence-уровни в математике

### R — Reproductive

Учащийся применяет знакомый метод в знакомой ситуации: решает типовое уравнение, выполняет стандартное преобразование, строит график знакомой функции, воспроизводит доказательство после разбора.

### T — Transfer

Учащийся применяет понятие или действие в новой ситуации узнаваемого типа: видит лишний корень в новой форме уравнения, строит контрпример, переносит геометрическую идею в алгебраическую задачу, объясняет тригонометрическое тождество через окружность.

### C — Constructive

Учащийся строит решение, где готовый шаблон не подходит: выбирает представление задачи сам, строит доказательство, создаёт модель, соединяет алгебру, геометрию и функцию, объясняет элементарное понятие с точки зрения высшей математики.

## CharacteristicSpace глубины математического знания

| Характеристика | Что означает |
|---|---|
| Object/Representation Distinction | Отличает объект от записи, графика, формулы, рисунка |
| Operation Legality | Проверяет допустимость операции |
| Equivalence Control | Отличает равносильный переход от следствия |
| Proof Responsibility | Понимает, где требуется доказательство |
| Counterexample Ability | Умеет разрушать ложные обобщения |
| Multi-Representation Transfer | Переходит между алгеброй, геометрией, функцией, текстом |
| Higher Viewpoint | Видит элементарное понятие из более общей рамки |
| Boundary Awareness | Видит область определения и границы метода |
| Modeling Ability | Строит математическую модель ситуации |
| Reflective Questioning | Формулирует вопросы T/C-уровня |

## Работа со Сканави

Сканави не используется как механическое натаскивание. Каждая задача привязывается к claim: техника преобразований, устойчивость к условиям, равносильность, параметры, неравенства, тригонометрия, геометрия, комплексное соединение тем.

## Работа с Клейном

Клейн используется для higher viewpoint. После чтения фрагмента учащийся отвечает: какое элементарное понятие переосмыслено; какая высшая точка зрения используется; что в школьном подходе становится видимым иначе; какую задачу теперь можно решить или объяснить по-другому.

## Работа с Александровым–Колмогоровым–Лаврентьевым

Используется для широкой картины математики, её методов, истории понятий и связи разделов. После чтения фиксируется содержательный тезис, методологический тезис, связь с текущим модулем и вопрос к ноосфере.

## Запреты

- Не закрывать claim по ощущению.
- Не засчитывать задачу, если решение не объяснено.
- Не переходить к анализу, если функция и предел остаются `🔴/🟠`.
- Не заменять геометрию рисунком.
- Не заменять доказательство вычислительным примером.
- Не использовать литературу как авторитет вместо действия.
