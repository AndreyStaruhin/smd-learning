# Onto-Map: математическое мышление — v0.2

## Назначение

Живая онтологическая карта курса. Обновляется после крупных сдвигов, не после каждой сессии.

---

# Уровень 1. Число и величина

**Объекты:** число, запись числа, величина, единица измерения, отношение величин, точное значение, приближение.

**Различения:** число ≠ запись; число ≠ величина; измерение ≠ вычисление; точность ≠ приближение.

# Уровень 2. Операция и преобразование

**Объекты:** операция, выражение, тождество, преобразование, условие допустимости, равносильный переход, следствие.

**Различения:** операция ≠ алгоритм; равносильность ≠ следствие; преобразование требует условий.

# Уровень 3. Уравнение и неравенство

**Объекты:** уравнение, решение, множество решений, неравенство, параметр, область допустимых значений.

**Различения:** выражение ≠ уравнение; решить ≠ преобразовать; корень ≠ решение без проверки; параметр ≠ переменная.

# Уровень 4. Геометрический объект

**Объекты:** точка, прямая, отрезок, угол, окружность, треугольник, площадь, подобие, преобразование.

**Различения:** фигура ≠ рисунок; рисунок ≠ доказательство; геометрическая интуиция должна быть проверяема.

# Уровень 5. Функция

**Объекты:** функция, аргумент, значение, область определения, область значений, график, формула, таблица, модель, композиция, обратная функция.

**Различения:** функция ≠ формула; график ≠ доказательство; локальное ≠ глобальное.

# Уровень 6. Тригонометрия

**Объекты:** угол, радианная мера, единичная окружность, синус, косинус, тангенс, период, тождество, тригонометрическое уравнение.

**Различения:** тождество ≠ уравнение; угол как величина ≠ градусная запись; тригонометрия ≠ набор формул.

# Уровень 7. Предельное мышление

**Объекты:** последовательность, предел, окрестность, приближение, бесконечно малое, непрерывность, разрыв.

**Различения:** значение в точке ≠ поведение около точки; приближение ≠ равенство; бесконечный процесс может иметь конечный предел.

# Уровень 8. Производная и интегральная идея

**Объекты:** приращение, отношение приращений, секущая, касательная, локальная линейность, скорость изменения, накопление, площадь, сумма, предел сумм.

**Различения:** средняя скорость ≠ мгновенная; секущая ≠ касательная; сумма ≠ интеграл без предельного перехода.

# Уровень 9. Higher viewpoint

**Объекты:** элементарное правило, общий принцип, структура, модель, доказательный метод, связь разделов.

**Различения:** школьное правило часто является частным случаем более общей идеи; higher viewpoint не заменяет элементарное действие, а переосмысляет его.
